ABOUT

I like software that has to be right, not just work in a demo.

I'm a third-year Computer Science undergraduate at IIIT, and most of what I build sits close to security, automation, or applied ML — systems where the interesting part isn't the UI, it's the decision underneath it: is this link a phishing attempt, is this farmer eligible for this scheme, is this price drop real.

I work mainly in Python, C++, JavaScript, React and FastAPI, and I'm comfortable owning a feature end-to-end — from the data layer to the API to the interface that explains the result to a non-technical user. I'd rather ship something smaller that's authenticated, tested and explainable than something larger that only works on stage.

Outside of my own projects, I've also worked as a collaborator on someone else's codebase (OcularX), which taught me a different skill: reading unfamiliar code carefully and shipping changes that don't break what's already there.
